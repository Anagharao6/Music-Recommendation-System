\# Music Recommendation System



A content-based music recommendation system built using Python, Pandas, and Scikit-learn.



\## Features



\- Reads song information from a CSV dataset

\- Uses audio features such as danceability, energy, acousticness, and valence

\- Calculates similarity between songs using cosine similarity

\- Recommends songs based on the selected song



\## Technologies Used



\- Python

\- Pandas

\- Scikit-learn
